# hosomichi 🚲 細道ルートナビ

大通りをできるだけ避けて、細い道を通る自転車ルートを自動で作り、そのままナビできます。
ブラウザだけで動きます（インストール・登録不要）。

👉 https://yopo777.github.io/hosomichi/

> ⚠ **自宅などが入ったルートを共有するのは自分だけにしてね。SNSなどに貼るときは注意！**
> 共有URL・QRにはルートの線がそのまま入ります。SNSなどに貼るときは、共有の画面の「出発地のまわりを隠す」「到着地も」を使ってください。

## はじめかた
1. 上のURLを **Chrome / Safari** で開く
   - X などのアプリの中で開くと、現在地が使えません。「︙」→「ブラウザで開く」で開き直してください
   - スマホは「ホーム画面に追加」するとアプリのように使えます
2. 「到着」に駅名・住所・GoogleマップのURLを入れて **Enter**（出発が空なら現在地から）
3. スタート付近のルートが出たら **◎** を押して走り出す。残りは走っている間に伸びていきます

## おすすめの使い方（パソコンで作ってスマホで走る）
スマホは道路データの取得がとても遅いので（モバイル回線・データの読みこみ・画面を消すと止まる）、パソコンで作ってスマホに送るのがいちばん快適です。
1. パソコンでルートを作る（はじめての設定は「ぜんぶ計算してから」。スマホで急ぐときは ⚙ 設定 →「すぐ走り出す」）
2. 「🔗 共有URL」→「📷 QR」でQRコードを出す（自分で使うだけなら「出発地のまわりを隠す」は「隠さない」でOK）
3. スマホのカメラでQRコードを読みとって開く（計算なしで一瞬で表示されます）
4. スマホで「💾 保存」しておけば、あとは「📁 保存したルート」から開いて ◎ で走るだけ

※ パソコンとスマホの「保存したルート」は自動ではつながりません。URLかQRで送ってください
※ スマホでもルートを作るときは、パソコンでためた道路データを「⬇ 書き出す」→ スマホで「⬆ 読みこむ」しておくと速くなります（下の「道路データをためる・わたす」）

## ルートを作る
- 場所の入れ方：駅名 / 住所（〒や建物名つきのコピペでOK）/ GoogleマップのURL / 緯度,経度 / 地図をタップ
  - **駅の出口**も指定できます：「柏駅東口」「柏駅 西口」「品川駅港南口」「大宮駅中央改札」など。駅のまわり500mで、その名前の出口 → バス停・乗り場 → 広場 の順にさがします（見つからないときは駅の場所を使います）
- 設定はぜんぶ自分の好みで決められます（⚙ 設定タブ）。「はじめの設定にもどす」でもとにもどせます
  - はじめの設定：ぜんぶ計算してから・曲がる回数 少なめ・地図の広さ せまい・4車線は信号か横断歩道で渡る・2車線はどこでも・一方通行は細い道なら逆向きも通る・階段は通らない
- **⚙ 設定** タブ（パネル上のタブ：🚲 ルート / ⚙ 設定 / 📜 ログ）
  - 計算のしかた：すぐ走り出す（スタートから順番に決める）/ ぜんぶ計算してから（少し良いルート）
  - 曲がる回数：気にしない / 少なめ / できるだけ少なく / とにかく少なく（曲がりが少ないと覚えやすいルートに）
  - 道の種類ごとの避けぐあい：住宅街・一般道・県道・国道・幹線国道・歩道・農道など（×1 〜 通らない）
  - 階段：通らない / 自転車スロープ付きだけ / 通る
  - 歩道橋・地下道、砂利・土の道の避けぐあい
  - 4車線以上の道を渡る：信号のある所だけ / 信号か横断歩道 / どこでも
  - 県道・国道を渡る：2車線の道と同じ / 4車線と同じ（車が多い・坂が多い所向け）
  - 右折レーンなどで3車線以上ある所は、4車線と同じ扱い（地図データに車線が書いてあるとき）
  - 2車線の道を横断歩道以外で渡る：どこでも渡る / 100m・300m・500m・1km までの遠回りなら横断歩道へ / 信号か横断歩道の所だけ
  - 川べりのサイクリングロード（江戸川・荒川など）：地図データで「自転車道」か「自転車の通行指定がある歩道・小道」になっていれば自転車道として使うよ。砂利の区間は砂利道あつかい
  - 一方通行の逆向き：細い道なら通る / 太い道でも通る / 通らない（橋・トンネル・「自転車も一方通行」の道は、どれでも逆向きに通らない）
    - 「太い道でも」：中央分離帯のある大きい道は反対側に行きにくいので、こちら側の**歩道を逆向き**に走ります。ルートでは「歩道（一般道の逆向き）」と出て、道の種類の色も歩道の色になります
- 歩行者・自転車用の踏切も使います
- 地図の丸い印（左下にも説明が出ます）：緑の丸＝出発 / 赤の丸＝到着 / 緑の輪＝信号で横断 / 青の輪＝横断歩道で横断 / 赤い輪＋黄色＝設定どおりに渡れなかった場所
- 赤い線＝決まったルート、赤い点線＝計算中（まだ変わるかも）
- 灰色の点線＝「ぜんぶ計算してから」でデータを待っているあいだの仮のルート（取れた所まで・4秒ごとにのびます。まだ変わるので見るだけに）
- **ゲージ**：どのタブを開いていても、パネルをたたんでいても見えます。計算中はしましまが動き、終わると緑になります
- 出発・到着は「ほかの道とつながっている道」の点に合わせます（駅の中の通路や公園の中の小道など、階段でしか行けない場所はゴールにしません）
- 保存していないルートがあるときに「ルートを作る」「✏ 新しく作る」を押すと、保存するか聞きます
- **✏ 新しく作る**：今のルートを消して、入力欄を空にして最初から

## 作れるルートの長さ
- **出発と到着は、まっすぐ 60km 以内**にしてください（それより遠いと「60km以内にしてね」と止まります）
- 長くなるほど、取る道路データ（マス）が増えて時間がかかります。目安（はじめての場所・地図の広さ「ふつう」）：
  - 〜6km：約550m角のマスで 数十マス。サーバーが空いていれば 数十秒〜1分くらい
  - 6〜20km：約1.1km角のマスで 50〜150マス。数分かかることも
  - 20km〜：100マス以上。スマホだとかなり待つので、パソコンで作るのがおすすめ
- 一度取った場所は保存データを使うので、2回目からはすぐです
- 共有：QRコードに入るのは 2,900文字くらいまで（だいたい 10〜20km）。長いルートはURLをコピーして送るか GPX で
- 長い旅は 1日ぶん（〜50km）ずつ区切って作って、それぞれ保存するのがおすすめです

ルートができたら「ピロリン♪」と音が鳴ります（マナーモードだと鳴らないことも）。

## 道路データをためる・わたす
いちばん時間がかかるのは道路データの取得です。前もってためておくと、ルートが一瞬でできます。
- 地図の見かた：端末に道路データがある所（次からすぐ使える所）だけ、地図が**カラー**になります。**青い点線**＝いま計算した範囲
  - いま取っているマスは**点滅**します（赤＝ルート計算で取っている所・オレンジ＝自動でためている所）
  - 道路データは「マス」ごとに取ります（約450m×550mか、約900m×1.1km）。出発と到着を結んだ線のまわりのマスを取ります
- **配布データ**：関東一円（1都6県・島はのぞく）は、道路データをまとめて GitHub に置いてあります（hosomichi-data・月1回くらい更新）
  - この範囲は、ルートを作るときにそこから取るので、OpenStreetMap のサーバーにアクセスせず速いです（自動）
  - 「📦 関東の配布データをまとめて入れる」で、範囲ぜんぶを先に入れておけます（数百MB・パソコン（Wi-Fi）向け）
- **☑ 地図のまわりの道路データを自動でためる**（🚲 ルートタブ）
  - ⚠ **パソコン（Wi-Fi・光回線）用です。スマホではオンにしないでください**（1日 最大100MBくらい通信します）。スマホでオンにしようとすると確認が出ます。モバイル回線やデータセーバーのときは自動でお休みします（わかる端末だけ）
  - チェックしておくと、**もう持っているマスのとなり**を、いつも使うあたりに近い順に、少しずつ外へ広げて取ります（いつも使うあたりから 20km まで）
  - まだ一度もルートを作っていないときは取りません
  - サーバーにやさしく：1マス（約1km角）ずつ・1マスごとに5秒休む・**1日300マスまで**（次の日にまた続きから）
  - 1年より古くなったマスがあれば、そちらの取りなおしを先にやります（いちばん古いものから）
  - **ルートの計算が始まったらお休み**（取っている途中のものも止めます）。終わったらまた続けます
  - このタブを開いているあいだだけ動きます。パソコンでつけっぱなしにしておくのがおすすめ
- **⬇ ためたデータを書き出す / ⬆ 読みこむ**
  - ためた道路データを1つのファイル（.hosomichi）にして、ほかの端末で読みこめます。パソコンでためてスマホに読みこめば、スマホはサーバーにアクセスしなくてすみます
  - 読みこむとき、自分のほうが新しいマスはそのまま残します
  - ⚠ ファイルを見ると、どのあたりをよく使っているか（自宅のまわりなど）がわかります。わたすのは自分の端末や信用できる人だけに
- サーバーの使いかたの目安：OpenStreetMap の Overpass API は「1日1万回・1GBより少なければほかの人のじゃまにならない」としています（IPアドレスごと）。ふつうに使うぶんには問題ありません

## ルート名
- 住所から作ったルートは「市＋町名」まで（丁目・番地は入れません）。「現在地」や地図タップで作ったルートも町名の名前になります
- 駅名・施設名で作ったルートは、その名前のままです（例：松戸市小金きよしケ丘 → 柏駅）
- ルートの説明の 📍名前 をタップすると変えられます

## ログ
- **📜 ログ** タブで、計算中にしていることを全部見られます（場所さがし・設定・マスごとの取得とサーバーの返事・待ち時間・区間ごとの計算・保存・坂の計算・エラー）
- 「コピー」でログをまとめてコピーできます。うまくいかないときの原因さがしに
- ほとんどの待ち時間は OpenStreetMap のサーバー（Overpass API）からの道路データの取得です。計算そのものは一瞬です

## ナビ
- **◎**：現在地ナビ（地図が追従・残り距離・ルートから60m外れたら警告・画面スリープ防止）
  - ナビ中は地図がずれません（拡大・縮小だけ）。もう一度 ◎ で解除
- **🧭**：北が上 / 進む向きが上（動き出すと回ります）
- **🎨**：ルートの色（赤 → 道の種類 → 坂）。左下に色の説明が出ます
  - 道の種類：細い道 / 自転車道 / 歩道・小道（押す所も）/ 一般道・県道 / 国道・幹線 / 歩道橋・階段・踏切 / 砂利・舗装不明・農道
  - 坂：のぼり 7%〜 / 4〜7% / 2〜4% / ほぼ平ら / くだり（国土地理院の標高データから計算。のぼり合計と一番急な所も表示）
- **⛶**：全画面（Android など。iPhone は「ホーム画面に追加」で）

## 保存・共有
- **💾 保存**：ルートを端末に保存して「📁 保存したルート」から開けます。前回のルートは自動で表示
- **🔗 共有URL**：ルートの線をURLに入れて共有（サーバーには保存しません）。**📷 QR** でQRコードも出せます
  - QRには線をなるべく間引かずに入れます（入りきらないときだけ少し間引きます）。長すぎるときはURLをコピーして送ってください
  - 自宅から出発したルートは「出発地のまわりを隠す」を使ってください（初期値 400m）。到着が自宅のときは「到着地も」にチェック
  - 共有の画面には「自宅などが入ったルートを共有するのは自分だけにしてね。SNSなどに貼るときは注意！」と出ます。出発地を隠さないで共有しようとすると、確認が出ます
  - ルートの**名前**もいっしょに送れます（共有の画面で変更可）
- **⬇ GPX**：ほかのナビアプリ用
- **途中から再開**：計算のとちゅうでも 💾保存・🔗共有URL ができます。あとで開くと「▶ 続きを計算」で、決まったところの先から計算を再開できます
  - 計算中は上の「■ 止める」でいつでも止められます（取った道路データは保存されます）
  - サーバーが混んでいるとき（HTTP 502 / 504・時間切れ など）は自動でがんばります
    - 1マスにつき 8秒返事がなければ次のサーバーにも同時にたのみ、早く返ってきた方を使います（1回 最大45秒）
    - 全部のサーバーがダメなら 10→20→40→60→90秒 と待ちながらやりなおし
    - 8割以上のマスがそろって 25秒新しいマスが来ないときは、手元のデータで先にルートを作ってみます（つながればそれで完成）
    - それでもダメなときは、しばらくしてから「▶ 続きを計算」
  - タブを閉じても、次に開いたときに「前回の計算が途中だったよ」と出ます
  - 続きは、計算をはじめたときの設定（細道の設定・地図の広さなど）で計算します
- 一度取った道路データは端末に保存（2回目からは速い）。1年より古くなっても、ルートを作るときは待たずにそのまま使います（取りなおしは「自動でためる」がゆっくりやります）。「📦 端末に保存した道路データ」の「消す」で削除

## iPhone で使うとき
- Safari（または iPhone の Chrome）で動きます。ルート作成・保存・共有・GPX・🎨・🧭・◎ナビは Android と同じです
- **位置情報**：はじめて ◎ を押したら「許可」。断ってしまったときは
  「設定」→「プライバシーとセキュリティ」→「位置情報サービス」→「Safari の Web サイト」を「この App の使用中」に
- **全画面ボタン（⛶）は出ません**（iPhone の Safari に機能がないため）。
  かわりに 共有ボタン（□↑）→「ホーム画面に追加」して、ホーム画面から開くとアドレスバーなしで使えます
- **おすすめはホーム画面に追加して使うこと**
  - Safari は、しばらく（7日くらい）開かなかったサイトの保存データを自動で消すことがあります。ホーム画面版は消えにくいです
  - Safari 版とホーム画面版は保存場所が別々です（保存したルートや道路データは共有されません）。どちらか片方で使ってください
- **画面が消えてしまうとき**：iOS が古いと画面スリープ防止が効かないことがあります。
  「設定」→「画面表示と明るさ」→「自動ロック」を長めにしてください

## うまくいかないとき
- **時間がかかる**：初めての場所は道路データの取得に時間がかかります。「自動でためる」を使うか、⚙ 設定の「地図データを取る広さ」を「せまい」に。完了時に「取得 / 計算」の時間が出ます（計算はふつう1秒もかかりません。待ち時間のほとんどは取得です）
- **スマホだと遅い**：モバイル回線は返事が遅く、届いたデータの読みこみもパソコンより時間がかかります。画面を消したりほかのアプリにすると止まります。パソコンでためた道路データを「⬇ 書き出す」→ スマホで「⬆ 読みこむ」すると、スマホはダウンロードなしですぐできます
- **ルートが見つからない**：⚙ 設定の「地図データを取る広さ」を広げてください（川や線路で大回りが必要な場所など）。設定で「通らない」にしている道（階段・歩道橋など）が多いとつながらないこともあります。📜 ログで「出発の点」「到着の点」を確認できます
- **現在地が出ない**：ブラウザで位置情報を許可してください。アプリ内ブラウザでは使えません
- **ナビが止まる**：画面を消したり、ほかのアプリに切りかえたりすると現在地の更新が止まります（ブラウザで動くため）。ナビ中は画面をつけたままにしてください
- **新しい版にならない**：新しい版が公開されると、画面の上に「🆕 新しい版があるよ［更新する］」が出ます（開いたとき・10分ごと・アプリにもどったときにチェック）。タイトル横の番号（例 v1109.2246）をタップしてもチェックできます。GitHub Pages は反映に数分かかることがあります
- 新しくルートを作りはじめると、画面の古いルートは消えます。とっておきたいルートは先に 💾保存 してください
